## Skill Creator — Create and Optimize Skills

Create new skills, modify existing ones, and optimize skill performance.

### Usage

```
"Create a new skill for [TOPIC]"
"Optimize the [SKILL-NAME] skill"
"Add AGI features to [SKILL-NAME]"
"Test skill performance"
"Run evals on [SKILL-NAME]"
```

### What It Does

1. **Creates Skills** — Full YAML frontmatter, AGI features, step-by-step
2. **Optimizes Skills** — Improves triggering accuracy, content quality
3. **Runs Evals** — Tests skill performance, measures success rates
4. **Modifies Skills** — Updates content, adds features, fixes issues
