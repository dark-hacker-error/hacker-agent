## Design — Visual Design Canvas

Create a design canvas for visual designs.

### Usage

```
"Create a design for [ITEM]"
"Make a mockup of [INTERFACE]"
"Design a landing page"
"Create a poster"
```

### Capabilities

| Type | Description |
|------|-------------|
| UI Mockups | App interfaces |
| Landing Pages | Web pages |
| Marketing | Social graphics |
| Print | Posters, flyers |
| Presentations | Slide decks |

### Output

- Multi-artboard canvas
- Pan/zoom interface
- Editable elements
- Export as PNG/PDF
