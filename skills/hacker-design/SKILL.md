## Hacker Design — Visual Design Skill

Design skill for creating artifacts, diagrams, prototypes, and visual designs.

### Usage

```
"Create a design for [ITEM]"
"Design a diagram of [SYSTEM]"
"Make a prototype for [APP]"
"Visual mockup of [INTERFACE]"
```

### Capabilities

| Type | Description |
|------|-------------|
| Diagrams | System architecture, flowcharts |
| Prototypes | Interactive app prototypes |
| Mockups | UI/UX visual mockups |
| Infographics | Data visualization |
| Presentations | Slide decks |

### Tools Used

- SVG generation
- HTML/CSS prototypes
- Mermaid diagrams
- ASCII art
