## OSINT — General Open Source Intelligence

General OSINT framework for intelligence gathering.

### Usage

```
"OSINT on [TARGET]"
"Find info about [PERSON/COMPANY]"
"Investigate [DOMAIN/IP]"
"Social media profile [USERNAME]"
```

### Categories

| Category | Methods |
|----------|--------|
| Person | Name, email, phone, username search |
| Domain | WHOIS, DNS, subdomains, tech stack |
| IP | Geolocation, ASN, reverse DNS |
| Social | Profile analysis, post history |
| Company | Employees, financials, tech |
| Breach | Data leak, credential exposure |
