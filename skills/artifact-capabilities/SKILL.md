## Artifact Capabilities — Runtime Features

Artifact runtime capabilities for interactive features.

### Usage

When creating artifacts, this skill provides:

- **State Management** — Save user input
- **Live Data** — Connect to APIs
- **File Upload** — Accept user files
- **Authentication** — User identity
- **Shared State** — Multi-viewer sync

### Capabilities

| Capability | Description |
|------------|-------------|
| State Save | Remember user actions |
| Live Data | Fetch real-time info |
| File Upload | Accept files |
| Identity | Know who's viewing |
| Sync | Share state across viewers |
