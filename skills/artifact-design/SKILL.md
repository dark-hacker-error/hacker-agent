## Artifact Design — Design Guidance

Design guidance and fundamentals for Artifacts.

### Usage

When creating visual artifacts, this skill provides:

- **Layout Principles** — Grid, spacing, hierarchy
- **Color Theory** — Palettes, contrast, accessibility
- **Typography** — Font selection, sizing, readability
- **Visual Hierarchy** — Importance ordering

### Design Principles

| Principle | Description |
|-----------|-------------|
| Contrast | Make elements stand out |
| Alignment | Create visual order |
| Repetition | Maintain consistency |
| Proximity | Group related items |
| Balance | Distribute visual weight |
