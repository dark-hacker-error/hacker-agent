## Hack Tools — Auto-Find and Install

Auto-find and install hacking tools from GitHub and web.

### Usage

```
"Find hacking tools for [PURPOSE]"
"Install [TOOL-NAME]"
"Find alternatives to [TOOL]"
"Set up hacking environment"
```

### What It Does

1. **Searches GitHub** — Finds trending hacking tools
2. **Installs Tools** — Automatically installs dependencies
3. **Configures** — Sets up tools for use
4. **Documents** — Creates usage documentation
