## Design Sync — Push to Claude Design

Push a React design system to claude.ai/design.

### Usage

```
"/design-sync" or "sync my design system to Claude Design"
```

### What It Does

1. **Bundles Components** — Packages real component code
2. **Uploads** — Sends to Claude Design platform
3. **Syncs** — Keeps design system updated

### Prerequisites

- React component library
- Storybook or bare package
- Claude Design account
