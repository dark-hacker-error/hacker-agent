## Artifact Diagramming — Diagram Know-How

Diagramming know-how for Artifacts.

### Usage

When diagrams would improve understanding:

- **Architecture Diagrams** — System design
- **Flow Diagrams** — Process flows
- **Sequence Diagrams** — Interaction timing
- **Entity Diagrams** — Data relationships

### Diagram Types

| Type | Use Case |
|------|----------|
| Architecture | System components |
| Flowchart | Decision processes |
| Sequence | API interactions |
| ER Diagram | Database design |
| Network | Infrastructure |

### Implementation

Uses inline SVG for crisp rendering in both light and dark themes.
