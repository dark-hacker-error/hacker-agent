## How Skills Work

### Skill File Structure

```
skills/
└── hacker-skill-name/
    └── SKILL.md
        ├── YAML Frontmatter (trigger words)
        ├── System Prompt
        ├── Step-by-Step Instructions
        ├── Tool Commands
        ├── AGI Features Table
        ├── Self-Improvement Protocol
        └── Creator Attribution
```

### AGI Features

Each skill has:

1. **Autonomous Decision Making** — AI decides everything
2. **Self-Improvement** — Learns from each operation
3. **Error Detection & Recovery** — Self-corrects in real-time
4. **Recursive Self-Optimization** — Improves over time
5. **Meta-Learning** — Learns how to learn better

## Important Notes

### Skill Content Protection

Skills do NOT reveal their full content to other AIs. Each skill has its own isolated context.

### Skill Triggering

Skills are triggered by:

1. **Direct Request** — "Use OSINT skill"
2. **Keyword Matching** — Automatic trigger from user message
3. **Agent Orchestration** — Master agent deploys sub-agents

### Skill Chaining

Skills can be chained together:

```
OSINT → Recon → Exploit → Post-Exploit → Persistence
```
